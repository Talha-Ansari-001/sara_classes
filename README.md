# Sara Classes Bhiwandi SPA

A high-end, premium educational SPA for "Sara Classes" in Bhiwandi. Designed with a **Modern Heritage** aesthetic and optimized for a luxurious user experience.

## Tech Stack
- **Frontend:** React 19, Vite, TypeScript
- **Styling:** Tailwind CSS (Custom palette: Gold, Deep Navy, Dark)
- **Animations:** Framer Motion (Evervault cards, Parallax reveals, Magnetic buttons)
- **Smooth Scroll:** Lenis
- **Icons:** Lucide React

## Key Sections
- **Hero:** Dynamic "Flip Words" headline and magnetic call-to-action buttons.
- **Academic Bento Grid:** Responsive asymmetric layout for Jr.KG to Graduation.
- **Philosophy:** Parallax cinematic brand storytelling.
- **Entrance Coaching:** Evervault-style glowing cards for NEET (Emerald), IIT-JEE (Sky Blue), and MHT CET (Indigo).
- **Contact:** Lead generation system with Miss Sara's details.
